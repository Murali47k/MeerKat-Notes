# MeerKat Notes

Personal interactive technical knowledge base, notebooks, mathematical derivations & animations.

🌐 **Live Website**: [https://murali47k.github.io/MeerKat-Notes/](https://murali47k.github.io/MeerKat-Notes/)

**Author**: Murali  
**Stack**: Astro + MDX + React + Manim + KaTeX + Tailwind CSS

## Getting Started

```bash
# Install Node dependencies
npm install

# Start local development server
npm run dev

# Build static production site
npm run build
```
